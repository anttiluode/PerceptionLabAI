# Workshop workflows

The [Workflow Manual](../docs/WORKFLOW_MANUAL.md) is the numbered index and Windows installation guide. Numbered JSON files are host-loadable graphs, not screenshots; 004 includes independent control workflows and explicitly measured calibration variants.

**004 current status:** [First measured result](../results/004_two_histories_initial.json) found suppression (A 21, B 0 together; B 4 alone) rather than alternation. The nine JSON graphs have measured calibration thresholds. See the [experiment dossier](../experiments/004_two_histories/README.md) before loading and note the GUI test is still outstanding.

**004 two-regime comparison:** [full-strength suppression](004_two_fades_one_field.json), [25% A return with alternating histories](004_weak_a_interleaving.json), and [25% A with B feedback unplugged](004_weak_a_without_b_return.json). [Long-run evidence](../results/004_two_histories_long.json) confirms 1,800 frames of alternation at A=0.30 or 0.45, and suppression at A=0.50. GUI execution of 004 is not yet verified locally.

**005 — AB vs BA order of falls:** [AB](005_AB_three_histories.json), [BA](005_BA_three_histories.json), [passive AB](005_AB_no_return.json), [passive BA](005_BA_no_return.json), [C-disconnected AB](005_AB_slow_disconnected.json), [C-disconnected BA](005_BA_slow_disconnected.json), [no stimulus](005_no_stimulus.json). All are experimental sources; the readout starts untrained. See the [Workflow Manual](../docs/WORKFLOW_MANUAL.md) and [005 dossier](../experiments/005_order_of_falls/README.md).
